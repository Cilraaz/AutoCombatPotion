# Auto Combat Potion

Auto Combat Potion is a variant of the addon Auto Potion by Ollidiemaus. This Addon will maintain a macro for you that will always show the most preferred combat potion based on user settings.

## How it works:

It's a very basic addon which will update the given macro every time you either login or your bags are updated. Therefore, it will keep up to date if you just pick up new combat potions.

## How to use:

1. Install Addon
2. Create a empty Macro called "AutoCombatPotion"
3. Move Macro to Button or Keybind it
4. reload
5. Profit!

## MegaMacro Compatibility

To use this addon alongside MegaMacro, you must first manually create a **Global** macro in MegaMacro, named `AutoCombatPotion`, then `/reload` your game.

Note: MegaMacro compatibility has not been tested and is not guaranteed.
